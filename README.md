# Legado Miuix

An independently maintained, unofficial Android reader project based on [Legado](https://github.com/LegadoTeam/legado), with a planned UI migration to Jetpack Compose and [miuix](https://github.com/compose-miuix-ui/miuix).

Maintained by [pinedrink](https://github.com/pinedrink). This project is not affiliated with or endorsed by the upstream Legado maintainers.

## Status

This repository is being initialized. At the time of this README's initial publication, the upstream application source has not yet been imported, and no application build is provided here.

The Compose and miuix migration is a project goal, not a claim of completed functionality. Future commits and release notes will document actual progress.

## Goals

- Gradually rebuild the user interface with Jetpack Compose and miuix.
- Preserve Legado's core reading capabilities throughout the migration.
- Follow Android platform APIs and lifecycle conventions.
- Maintain this project independently while tracking relevant upstream changes.
